# 目录维护记录

这里保存完整目录核对过程，不进入GitHub Pages发布目录。仓库公开，因此这些记录可供贡献者查看。

- `review-queue.json`（构建生成，排除出版本跟踪）：构建时从完整源自动生成的索引、评级、身份和日期复查队列；若有旧年正面评级，记录采用的参考年份。
- `master-candidates.json`：用户参考目录的文件名、SHA-256指纹、行号、稳定编号及对应问题。
- `expansion-v0.8.json`：本次新增编号、历年完整来源及身份对应复查。

先按ISSN、正式名称和已核实的更名关系核对来源，再修改对应的`data/venues/`或`data/calls/`源文件。维护标记不替代等级，不以同缩写会议赋值。修改后运行测试、校验、构建与覆盖报告；网页只发布明确属性。
