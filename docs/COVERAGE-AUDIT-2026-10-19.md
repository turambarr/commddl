# CommDDL 目录覆盖核查（2026-10-19）

核查对象：v0.6.0，108本主目录期刊、136个主目录会议系列。历史参考39项不计入；同一期刊多索引不互斥。

结论：国际主流载体已有基础覆盖，但目前不能称为通信领域相对完整目录。主要缺口是国内中文期刊、部分英文通信期刊、非WoS索引属性以及会议截止记录。本文为有限来源对照，不估计全球通信载体总数或整体覆盖率。

## 1. 已有数量与含义

| 属性 | 已录入匹配数 | 解读 |
|---|---:|---|
| SCIE（科学引文索引扩展版） | 89 | 占期刊目录82.4%，按条目所列年份证据 |
| ESCI（新兴来源引文索引） | 15 | 与SCIE在本站分开，不能当作同一等级 |
| WoS（科学引文数据库）证据不足 | 4 | 不据此认定非SCI |
| EI（工程索引） | 5 | 仅已有属性记录数，明显漏标 |
| CSCD（中国科学引文数据库） | 3 | 仅已有属性记录数 |
| Scopus（摘要与引文数据库） | 2 | 仅已有属性记录数，明显漏标 |

SCI/SCIE与EI、Scopus可能同时收录同刊，不能把上述数字当成互斥等级分布。当前仅4个中文刊名记录：通信学报、电子学报、电子与信息学报、信号处理。中国主办的英文刊另计，不包含在这4本中。

## 2. 索引属性的实证漏标

[IET Communications出版方简介](https://ietresearch.onlinelibrary.wiley.com/hub/journal/17518636/homepage/productinformation.html)同时列出SCIE、Compendex与Scopus；[IET Signal Processing出版方简介](https://ietresearch.onlinelibrary.wiley.com/page/journal/ietsp/homepage/productinformation.html)亦列出这三项。两刊都在本站目录，但其otherIndexes字段没有EI和Scopus记录，因此被相应筛选漏掉。

这两个例子已足以证实“属性没填全”，不能据EI=5、Scopus=2推断通信领域只有这么多选择。其余106刊本轮未逐一完成多索引复核，不报未经证实的总量。

## 3. 会议覆盖的有限对照

对照[IEEE ComSoc（电气电子工程师学会通信学会）官方会议组合目录](https://www.comsoc.org/conferences-events/portfolio-conferences-events)，人工选取42个常规会议/研讨会系列对比全称、简称与已有别名，42个均已收录。该页若干峰会没有当作同等论文发表载体纳入这个参照集。这不是全球会议覆盖率，也不证明每个会议当前都接受正式论文。

参照集：GLOBECOM、ICC、CCNC、INFOCOM、NOMS、WCNC、MILCOM、CAMAD、CloudNet、CNS、CSCN、CTW、DySPAN、HealthCom、HPSR、ICBC、ICMLCN、ICSOS、IS2、LANMAN、NetSoft、NFV-SDN、SECON、SmartGridComm、ANTS、BlackSeaCom、LATINCOM、MECOM、MeditCom、OFC、ATC、ICCC、ICME、ISCC、IWQoS、JC&S、PIMRC、QCE、VNC、FNWF、WF-IoT、VCC。

136个会议系列中，55个有届次/活动记录，53个有明确主要投稿截止日期（约39.0%，含往届）。因此“会议名在目录”和“当届可以用来安排投稿”是两个不同的完成度；本次不把已过期日期当作当前可投稿机会。

136个会议系列按已列评级版本，CCF（中国计算机学会）明确A/B/C共30个，ICORE（国际合作会议评级）明确A*/A/B/C共46个；所查版本未列入、合并对应未明确、非等级状态分别保留。CCF是计算领域推荐目录，不是所有通信会议的完整目录，未列入不等于低等级。

## 4. 缺录候选：34本期刊、6个会议示例

对候选逐项比对主目录与历史库的正式名称、简称和已有别名，未发现对应记录。部分依据[中国电子学会2023正式分级目录](https://www.cie.org.cn/list_42/11930.html)发现；该目录包括更广的电子技术领域，不能用其232总数减去本站108来计算通信缺项。本文仅挑选与通信、网络、信号、射频光通信直接相关的一组条目。

旧目录证明历史身份，不单独证明2026仍在接收投稿，也不作为当前SCIE/EI/分区证明。候选不是已导入目录；正式补录时还要核实当前出版、作者入口与索引年份。2025年末发布的2026候选名单也不当作最终2026评级。

## 5. 建议的修订顺序

1. 先逐刊补齐既有108刊的EI、Scopus、CSCD、北大核心等明确属性，给每项记录来源、核验日期和适用版本；没有记录不显示成否定。
2. 优先补国内通信中文刊和直接通信英文刊。先核查本报告34本，再按出版社和学会逐组扩展，不设置凑数量目标。
3. 继续补录会议当届时间；每个系列区分未公布、已核验日期、尚未读取与停办/合并。
4. 再扩展普通会议与附属研讨会，逐届区分已检索和拟送检，不沿用主会等级。
5. 每次扩充同时检查方向覆盖、索引属性完整度、当届日期完整度，分别报告；只有名称数增加不代表日历更完整。
