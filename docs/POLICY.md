# 选用的北邮学位成果文件

本项目按《北京邮电大学关于研究生在读期间公开发表学术论文要求的规定（2018年6月修订）》整理相关条款。[学校公开原文](https://xxgk.bupt.edu.cn/__local/F/65/92/3A361334F005A224CD3C6C215B7_43DF8061_C1241.pdf?e=.pdf)；完整PDF读取日期为2026-10-18。

## 适用范围与条款

- 第七条、第九条：适用于全日制学术型研究生，自2018级起执行；2018级以前可选择相关版本。
- 第三条，PDF第1页：工学、军事学博士的一条路径是2篇第一作者SCI（科学引文索引）刊源论文；另一条路径是1篇SCI，加2篇EI（工程索引）刊源或学科指定重要国际会议论文。计算机、软件工程适用另行条款。
- 第四条，PDF第2页：硕士学术论文路径包括公开发行的学术性刊物、全国性或国际学术会议、国内外二级以上学会会议论文集，另有指定在线发表渠道。
- 第二条、第四条：成果要求涉及在读期间、北邮第一署名单位、正式发表证明及作者身份。第四条写明第一作者，第二条另述导师第一作者、本人第二作者情形；具体路径需结合两条核对。
- 第五条：另列科研奖励、发明专利等替代规则。

## 在目录中的用法

网站整理通信相关投稿渠道，硕士会议按第四条所列范围查找。“2018重要会议表”作为独立历史标签，完整89项身份映射见[目录文档](CATALOG.md)。

目录用于选刊选会。个人成果认定需结合适用培养要求、具体届次、稿件类型和发表证明核对。
