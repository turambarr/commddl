# 选用的北邮学位成果文件

本项目按用户指定的《北京邮电大学关于研究生在读期间公开发表学术论文要求的规定（2018年6月修订）》整理：[学校公开原文](https://xxgk.bupt.edu.cn/__local/F/65/92/3A361334F005A224CD3C6C215B7_43DF8061_C1241.pdf?e=.pdf)。2026-10-18 已读取用户提供的完整 PDF；这是指定版本的解释，不宣称已核验现行全部培养要求。

- 第三条，PDF 第1页：工学、军事学博士的一条路径是2篇第一作者 SCI（科学引文索引）刊源论文；另一条路径是1篇 SCI，加2篇 EI（工程索引）刊源或学科指定重要国际会议论文。计算机、软件工程的另行条款不能自动用于信息与通信工程。
- 第四条，PDF 第2页：硕士的学术论文路径允许公开发行的学术性刊物、全国性或国际学术会议、国内外二级以上学会会议论文集；另有指定在线发表渠道。没有规定会议必须属于重要会议表。
- 第二条及第四条：须注意在读期间成果、北邮第一署名单位、正式发表证明、作者身份。第四条写明第一作者，第二条另述导师第一作者、本人第二作者情形；本项目保留两条表述，不自行判定其在具体硕士路径中等效。
- 第七条及第九条：适用于全日制学术型研究生；原文规定自2018级起执行，2018级以前可选择相关版本。本项目不将其自动推广到所有专业学位研究生。
- 第五条另列科研奖励、发明专利等替代规则。本轮聚焦论文投稿目录，不据此开发自动毕业资格判定。

因此，网站默认展示重要会议表以外的通信相关候选渠道。“2018重要会议表”保留为独立历史标签，不作为硕士的排他筛选条件。完整89项映射见 [目录审计](CATALOG.md)。目录收录只表示提供候选渠道，不保证某届、每种稿件形式或任何个人论文已经满足学位条件。
