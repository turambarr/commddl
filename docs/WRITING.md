# 文案维护约定

页面文案先帮助读者查找、筛选和安排投稿。条目说明直接写核对结果与依据。

## 页面、条目与使用说明

- 页面写操作和结果：查什么、选什么、何时截止。
- 条目写事实和来源：核对对象、版本、结果、适用范围、具体信息缺口。
- 来源说明集中解释索引与分区的关系、版本口径及状态含义。
- 日期导出旁保留精度提示，政策说明写明选用文件与适用对象。

## 写法示例

| 修改前 | 修改后 |
|---|---|
| 结论限本公开副本，未列入不代表低等级。 | 核对CCF2026公开副本全部386个会议条目，未列入该版。 |
| 不冒充原库或2026数据。 | 来源为高校公开的2025升级版完整转录。 |
| 核验日期不是数据库新版年份。 | 页面未注明数据库版次；另记本次读取日期。 |
| 常规期刊不会自动生成截稿时间。 | 期刊按载体建目录，专题按具体征稿记录截止。 |

## 保留准确性

明确时刻、仅日期、未知时间分别展示；正式长文、附属研讨会和演示分别认定评级。来源年份、学科、适用刊名、转录或副本属性、访问失败和日期冲突，均在相关条目保留。

来源短引文和历史核验记录保留原文。修改解释性文字时，对比目录数据中的身份、索引、评级、日期、状态和来源链接，再运行现有业务检查。

## 版本记录

v0.7.1依据Anti-Defensive Writing（反防御性写作）修订页面、813处数据说明及当前维护文档。数据字段逐项对比v0.7.0，变化限于解释性文字与版本号。历史覆盖审计、扩充记录及已有QA（质量检查）条目按原版本保留。

## v0.8 页面与维护记录

读者页面展示明确属性、真实年份和来源。未知、未列入、未匹配及访问失败说明进入完整维护源和`maintenance/`；不生成空等级徽章或未知筛选按钮。注册资料入口称“刊物信息”，停刊资料称“出版档案”，邀请制刊物显示邀请方式。
