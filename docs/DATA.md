# 数据与维护约定

## 收录边界

首批基础目录为 24 个会议系列、30 本期刊；32 条活动记录中有 11 条已经读取官方来源，其余为当前届次待核验入口。会议目录已核实不代表该会下一届截止已经确认。

信息来自学会、期刊与具体会议官方页面，条目中保存 `sourceUrl`（来源网址）和 `verifiedAt`（核验日期）。专题中文标题是便于检索的翻译，正式题名以英文和官方页面为准。

本版没有批量导入 2018 年学校目录的全部编号，也没有将此前“86 本未列期刊”的差集当作通信期刊全集。

## 主要对象

| 字段 | 中文含义 | 说明 |
|---|---|---|
| `venues` | 载体目录 | 会议系列或期刊，使用独立且稳定的编号 |
| `calls` | 具体活动 | 某届会议、附属研讨会、期刊专题或持续栏目 |
| `venueId` | 所属载体编号 | 关联已有载体 |
| `kind` | 类型 | 主会、附属研讨会、专题、持续栏目分别保存 |
| `areas` | 研究方向 | 多选，必须使用方向表中的编号 |
| `nodes` | 时间节点 | 投稿、摘要、录用、终稿等分别记录 |
| `verification` | 核验状态 | `verified` 已读取来源；`pending` 待核验 |
| `assessments` | 评价或目录依据 | 每项独立保存体系、年份、来源及适用说明 |
| `publicationType` | 刊物类别 | 研究型期刊、快报期刊、专题期刊、综述期刊、学术杂志 |
| `articleTypes` | 可投稿文章类型 | 研究论文、快报、综述、教程等，不能与刊物类别混同 |

期刊的投稿方式目前以“作者指南中核实”或明确的专题方式展示。没有逐刊确认时不统一写“全年接收”。

## 时间精度

`precision`（精度）可取：

- `instant`：明确时刻。`instant` 字符串必须包含 UTC（协调世界时）偏移，例如 `2026-10-30T23:59:59-12:00`；同时记录官网时区说明。此例仅说明格式，并非某个会议日期。
- `date`：仅日期。填写 `date`，`instant` 和 `timezone` 均保持空值。
- `unknown`：尚未确认，不生成倒计时或日期事件。

`original` 保存必要的官方日期短表述。不要把网页内容管理系统的文章发布时间当成投稿截止钟点。`requires` 是前置节点的稳定编号列表，例如全文投稿需要先完成摘要注册。

明确标注 AoE（全球任何地方当天结束）时采用 UTC−12。美国太平洋时间要按截止当天确定夏令时偏移，不用全年同一偏移。

官网有明确日期但未说明开放时间时，网站显示日期已公布，不据此保证投稿系统此刻已经开放。仅日期已过时显示“公布日期已过”，具体状态以官网为准。

## 延期、新轮次与取消

活动和节点编号不能随排序改变。延期更新日期，递增节点 `revision`（修订序号），保存旧值、变更依据和 `updatedAt`（更新时间）。新投稿轮次增加新的稳定节点编号。

取消时保留原节点，活动状态设为 `cancelled`（已取消），递增修订序号；生成的日历记录保留原 UID（事件唯一编号）并增加取消标记。停止维护的活动保留历史，避免订阅端失去修订依据。

本版 JSAC 可移动天线专题的官网注明已延期，但没有核实旧日期，因此只保留“已延期”的证据，不虚构此前数值。

## 已发现的来源问题

- 一些会议网站本次无法直接读取，因此其具体届次与日期保持待核验。
- 无线通信杂志水下无线光通信专题的官方页面存在首次决定年份早于初稿截止的异常。投稿截止与官方总表一致，已录入；异常通知节点没有自动纠正或写入。
- VTC 附属研讨会记录是大会官方总入口；具体研讨会可能有独立要求，需要逐一核实，不继承主会标签。
- 分区、当前 SCIE 收录和当前学院适用政策尚待专门核验，页面不填未经核实的数值。

## 提交流程

修改 `data/catalog.json` → 核对官方证据 → `npm test` → `npm run build` → 检查页面预览 → 提交变更。

格式校验只检查结构和业务约束。维护者仍须人工确认网址对应正确届次、摘要与全文区别、时间精度和学校文件范围。

有字段冲突时标记 `conflict`（冲突），保留来源说明；不要挑一个方便的日期直接发布。第三方日历只用于发现线索。
