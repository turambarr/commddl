# 数据与维护约定

## 收录边界

v0.11.0 主目录325本期刊、340个会议系列，9个方向、46个主题；另有41项历史参考。维护源93项活动，公开发布89项（88项有投稿截止，1项持续栏目）。

主题分类与评级、索引分别维护，按官方介绍人工归类。学校历史文件保留89条身份追溯，主目录按通信主题整理。目录及来源见 [目录清单](CATALOG.md)，复查缺口见 [核验记录](VERIFICATION.md)。

## 主要对象

| 字段 | 中文含义 | 说明 |
|---|---|---|
| `venues` | 载体目录 | 会议系列或期刊，使用独立且稳定的编号 |
| `calls` | 具体活动 | 某届会议、附属研讨会、期刊专题或持续栏目 |
| `venueId` | 所属载体编号 | 关联已有载体 |
| `kind` | 类型 | 主会、附属研讨会、专题、持续栏目分别保存 |
| `areas` | 研究方向 | 多选，必须使用方向表中的编号 |
| `primaryArea` / `secondaryAreas` | 主方向 / 辅方向 | 一个主方向、最多两个辅方向，`areas`依次为主方向和辅方向 |
| `urlKind` | 入口类别 | `registry`是刊物注册资料，页面称“刊物信息”；出版方入口单列 |
| `topics` | 具体研究主题 | 多选稳定编号，期刊、会议、活动共用主题表 |
| `topicReviewedAt` | 分类整理日期 | 与官方事实核验日期分开记录 |
| `authorGuideUrl` / `cfpUrl` | 作者指南 / 征稿入口 | 可选；只补充已找到的官方入口 |
| `nodes` | 时间节点 | 投稿、摘要、录用、终稿等分别记录 |
| `verification` | 核验状态 | `verified` 已读取来源；`pending` 待核验 |

| `publicationType` | 刊物类别 | 研究型期刊、快报期刊、专题期刊、综述期刊、学术杂志 |
| `articleTypes` | 可投稿文章类型 | 研究论文、快报、综述、教程等，与刊物类别分别保存 |

常规期刊列入载体目录，专题单列为活动；接收方式见各刊作者指南。

## 时间精度

`precision`（精度）可取：

- `instant`：明确时刻。`instant` 字符串必须包含 UTC（协调世界时）偏移，例如 `2026-10-30T23:59:59-12:00`；同时记录官网时区说明。此例仅说明格式，并非某个会议日期。
- `date`：仅日期。填写 `date`，`instant` 和 `timezone` 均保持空值。
- `unknown`：尚未确认，不生成倒计时或日期事件。

`original` 保存必要的官方日期短表述。不要把网页内容管理系统的文章发布时间当成投稿截止钟点。`requires` 是前置节点的稳定编号列表，例如全文投稿需要先完成摘要注册。

明确标注 AoE（全球任何地方当天结束）时采用 UTC−12。美国太平洋时间要按截止当天确定夏令时偏移，不用全年同一偏移。

官网给出日期时，网站显示“日期已公布”；日期经过后显示“公布日期已过”。投稿系统的开放与关闭状态见官方入口。

## 延期、新轮次与取消

活动和节点编号不能随排序改变。延期更新日期，递增节点 `revision`（修订序号），保存旧值、变更依据和 `updatedAt`（更新时间）。新投稿轮次增加新的稳定节点编号。

取消时保留原节点，活动状态设为 `cancelled`（已取消），递增修订序号；生成的日历记录保留原 UID（事件唯一编号）并增加取消标记。停止维护的活动保留历史，供订阅端更新记录。

JSAC可移动天线专题官网注明已延期，旧日期尚未核实，保存延期说明与当前日期。

## 已发现的来源问题

- 一些会议网站本次无法直接读取，因此其具体届次与日期保持待核验。
- 无线通信杂志水下无线光通信专题的官方页面存在首次决定年份早于初稿截止的异常。投稿截止与官方总表一致，已录入；异常通知节点没有自动纠正或写入。
- VTC 附属研讨会记录是大会官方总入口；各研讨会分别核实要求和适用标签。
- JCR、SCIE/ESCI 按已读取的出版社快照；CCF公开副本与中科院第三方转录单独标注证据。评级与历史身份映射独立维护。

## 提交流程

阅读 `data/README.md` → 修改对应 YAML 源文件 → 核对官方证据 → `npm run check` → `npm test` → `npm run build` → 检查差异 → 提交合并请求。

格式校验检查结构和业务约束；事实核验检查官方来源、届次、稿件类型、时间精度和评级对应身份。

字段冲突标记为`conflict`（冲突），保留各来源说明，核实后发布明确日期。第三方日历用于发现线索。

## 分类与筛选规则

方向代码 WC、SP、IT、NET、OPT、EM、SAT、IoT、AI 是本项目的方向导航缩写。具体主题可属于多个方向；载体的方向与主题由编辑按载体内容整理。

多选具体主题匹配任一项，再与所选方向、关键词、类型等条件共同筛选。切换方向后清除不属于新方向的主题；筛选状态保存在地址中的 `topics` 参数，刷新与分享可恢复。未知主题编号会被忽略。主题旁数字表示当前方向、关键词、类型等条件下该主题的独立结果数，多主题合并后会去重。

专题按自身征稿内容分类，母刊主题用于载体导航。SAM等独立研讨会按会议系列维护，workshop（附属研讨会）按附属活动维护。

SenSys、IPSN、IoTDI 合并后按统一 SenSys 系列计数，旧名称作为别名。MWTL 的旧称 MWCL 保留检索。目录来源可以是学会的出版物或会议总表；总表用于核对载体身份与概括主题；具体截止、录用率及评级各有独立来源。

## 评价字段与匹配规则

`evaluations`（评价记录）为每个体系独立保存 `system`（体系）、`year`（原表年份）、`releaseYear`（发布年，如有）、`snapshotDate`（快照日期，如有）、`value`（明确数值或空值）、`status`（证据状态）、`sourceUrl`（来源网址）、`sourceType`（来源类型）、`note`（范围说明）。中科院另存大类 `category` 及小类 `minorCategories`；大类筛选读取大类值。

- `verified`：一手来源明确值；`reported`：第三方转录或原始文件公开副本，附原始版本。
- `pending`：待核验；`not-matched`：本次未建立确定对应，保留匹配缺口。
- `scope-review`：合并或改名后的适用范围待认定；`non-ranked`：原库明确的非等级状态，不映射为 C。
- 匹配使用正式全名、已核实别名及ISSN。同缩写分别核对：CL可指IEEE通信快报或Computer Languages（计算机语言），CTW可指IEEE通信理论研讨会或Cologne-Twente（科隆—特温特图论研讨会），ICCC可指中国通信会议或计算创造力会议。
- CCF会议评级仅适用于对应正式长文，附属研讨会、演示、短文等不自动继承；学校历史目录筛选同样排除附属研讨会继承。
- JCR与中科院分区适用于期刊。SCIE、ESCI依据明确索引列记录，JCR分区独立保存。
- 中国科学院文献情报中心[2026年3月声明](https://las.cas.cn/news/tzgg/202603/t20260327_8178738.html)明确自2026年起停止更新发布；新锐分区不能标成中科院2026版。

`catalogStatus`（目录状态）独立于评价：`current`表示已有官方身份来源，征稿状态在具体活动中记录；`needs-review` 为当前信息待核验；`historical-only` 为仅有历史文件记录。按名称与主题搜索仍可找到历史条目。

`legacyMappings`（原表映射）保存全部89个原编号、原简称、PDF页码和对应载体编号。`policy`（选用文件）保存选用文件的版本、条款及适用范围。

运行 `node scripts/coverage.cjs` 可从原始数据重新生成目录审计。结构校验、业务测试与官方事实核验分别记录结果。

## v0.4 索引、核验状态与组合筛选

`indexing`保存WoS（科学网）索引SCIE/ESCI等，`otherIndexes`保存已独立核验的EI、Scopus、CSCD等；每项有来源和日期。旧年度转录保存`year`及`sourceType: secondary`，按原始版本展示。

评价与索引状态：`verified`为一手来源；`reported`为明确版本的转录/副本；`unlisted`为完整所查目录未列；`unresolved`为已复查但证据不足；`scope-review`为更名合并后的对应未明确；`non-ranked`保留库中非等级原文；`not-applicable`为不适用。新数据不再使用笼统的`not-matched`。历史状态按原意兼容读取。

`reviewedAt`是复查日期，`attempts`记录访问或匹配方法。`sourceUrl`保存已查来源或访问入口；明确等级需有正面证据。`snapshotDate`允许精确日期或仅月份，不能为月份补造某一天。

地址参数`ranks`保存多选评级；同体系或、跨体系且，再与索引、主题、方向和搜索共同匹配。会议不接受期刊分区过滤，期刊不接受ICORE评级过滤。`N`只兼容旧维护记录，网页不再生成或接受该筛选项，学术等级保存在`value`。

`catalogScope: communications`为主目录；`archive`为历史参考。默认隐藏档案，可显式包含；已有档案收藏仍可访问。稳定编号、别名与89条历史映射不因归档而删除。

LetPub（公开期刊查询平台）的页面可能混有`display:none`的不同数值。只提取2025年3月对应表格中可见内容，分清大类与小类，不使用新锐2026或隐藏文本。转录数据保持第三方来源属性。

## v0.5 截稿与届次选择

首页默认隐藏已过日期；没有截稿时间的届次保留在维护源，已过日期可主动显示。会议目录优先显示可提交的下一轮主会时间，附属研讨会与演示不替换主会日期。常规期刊保持目录身份，专题独立设置截止。

`eventStart` / `eventEnd` 为已核实的召开日期；`sourceTimezone` 为仅日期情况下已知的原时区，钟点单独核实。`submissionDateStatus: TBA` 表示官网明确待公布，未读到截稿不能标成官网待公布。`inheritsVenueEvaluation: false` 表示独立分会或演示不能继承旧系列评级。

`callAliases` 保存旧占位活动到具体届次的编号映射，兼容旧收藏和分享链接。新轮次独立保存；摘要注册已关闭的轮次显示前置条件限制。

内容管理系统时间、过时模板、第三方推测日期均不作为精确截稿证据。逐项记录见 [截止时间清单](DEADLINES.md)。

## v0.6 搜索与属性筛选

期刊与活动共享明确收录、分区和评级过滤。搜索先解析SCI/SCIE/ESCI/EI/CSCD/Scopus、JCR Q1–Q4、中科院一至四区及CCF/ICORE等级，余下文本按原名称与主题搜索处理。SCI映射SCIE，未知状态不从刊名或分区推断。查询与显式选项同时约束结果。

页面显示条件匹配数量，完整期刊入口与具体活动结果分开。维护与用法见[FILTERS.md](FILTERS.md)。本次未更新索引和分区事实快照。

## v0.7 扩充与索引补漏

补录依据为逐刊官方身份、作者入口及独立索引证据。索引可以重叠，新增中文核心、科技核心搜索与筛选，各索引按独立属性保存。

CSCD（中国科学引文数据库）按2025—2026年度名单及ISSN复核，保留核心库、扩展库区别；匹配缺口保留为未确认状态。新刊JCR、中科院和CCF/ICORE采用已取得完整版本逐项匹配，保留年份、转录或副本属性。

中文与英文同名期刊按各自ISSN区分；特别是《中国科学：信息科学》中文版不与SCIENCE CHINA Information Sciences英文版合并。常规期刊列目录，专题按具体征稿记录截止。

部署方式见[DEPLOYMENT.md](DEPLOYMENT.md)。

## v0.8 发布分离与历史评级

`data/venues/`、`data/calls/` 中的 YAML 是完整维护源；`data/catalog.json` 是编译生成的兼容目录。`scripts/public-catalog.cjs`按字段白名单生成读者数据；`assets/data.js`、`dist/data/catalog.json`、日历和离线HTML共用该结果。`maintenance/`、`docs/VERIFICATION.md`及原始资料均不进入Pages构建。公开仓库仍可查看维护源，维护记录不是私密服务。

评价唯一键为`system:year`，同一载体保留多个年份。卡片和等级筛选使用每体系最近的明确正面等级，详情保留所有年份。新版本未列时可显示旧版参考，但年份保持原值。CIE2023（电子学会）与CIC2021（通信学会）使用独立体系编号。

索引仅由明确索引列赋值，不从JCR分区、学会分级或刊名推定。匹配忽略N/A等无效ISSN。旧名评级对应到新名需要出版方或注册资料说明连续关系，不能凭同缩写迁移。

公开活动需要已核实的主要截止日期或持续栏目属性；日期未知、冲突或前置步骤不完整的轮次保留维护源。被移出公开活动的旧收藏映射到母载体，延期的稳定节点编号保持不变。

用户总目录作为身份候选与分类参考：264条期刊记录完成对应；文件中的无年份分区、COMM_TIER自定义等级和毕业认定文字不直接变成评级属性。文件指纹、行号及映射保存在`maintenance/master-candidates.json`。

## v0.9 独立 YAML 源文件

维护入口见 [`data/README.md`](../data/README.md)，Agent 自动指引位于 [`data/AGENTS.md`](../data/AGENTS.md)。期刊和会议系列放在 `data/venues/<primaryArea>/<id>.yml`，届次、轮次、专题放在 `data/calls/<year>/<id>.yml`；持续栏目使用 `rolling/`。文件名与编号、主方向目录与字段、年份目录与届次必须一致。

编译器采用 YAML 1.2，拒绝重复键、别名、合并键及不可表示为 JSON 的数值，按稳定编号排序。`npm run check` 和测试直接读取源文件；`npm run compile` 可单独生成兼容 JSON，`npm run build` 校验后生成全部发布产物。公开投影、评级与索引规则保持原语义。

合并 JSON、网页数据、订阅日历和核对队列由工具生成并排除出 Git 版本跟踪，普通贡献只提交源文件。公共版本和报告由维护者发布时整理。数据更新时间取公共日期与条目中核对、修订日期的最大值，贡献者无需修改公共版本文件。

网站的“GitHub 提交修改”只打开对应源文件，修改通过 GitHub PR（合并请求）检查、审核、合并后发布。

## 剩余天数筛选

`within=7/30/90/180` 保持原来的未来天数链接；`within=custom&from=30&to=40` 表示包含起止两端的30—40天。`from`为空默认0，`to`为空不限上限，两端均空不限制。有效值是0—36500的整数，反向区间显示输入提示并返回空结果。

日期按当前显示时区的日历天计算，分享区间同时保留时区；明确时刻已经过去的记录即使在同一日也不匹配。持续征稿、没有日期的记录、取消和日期冲突记录不进入有限区间。摘要前置条件已关闭的活动保留原有提示。

期刊按具体专题、会议按正式会议征稿选取匹配区间的活动。先筛选所有候选轮次，再选卡片展示的活动，防止“最近一轮不在区间、下一轮在区间”被漏掉。筛选数量、卡片时间、导出与分享使用同一条件。
