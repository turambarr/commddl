# 数据与维护约定

## 收录边界

v0.3 目录包含149个会议系列记录、80本期刊，9个方向、37个主题；会议数包含仅历史文件记录。32条活动中11条已读取具体官方来源。新增系列不自动生成届次或推测日期。逐条保存身份来源、评价来源和不同核验状态。

分类与逐条来源见 [目录覆盖清单](CATALOG.md)。本轮以通信及主要交叉方向的常用载体为范围，尚非通信领域全集。

信息来自学会、期刊与具体会议官方页面，条目中保存 `sourceUrl`（来源网址）和 `verifiedAt`（核验日期）。专题中文标题是便于检索的翻译，正式题名以英文和官方页面为准。

本版已保留2018重要会议表全部89项编号映射，合并重复但不删除原映射；身份不明确的条目不强行对应。此前期刊差集不作为通信期刊全集。硕士成果范围按第四条解释，重要会议表对应第三条博士路径之一，详见 [文件条款](POLICY.md)。

## 主要对象

| 字段 | 中文含义 | 说明 |
|---|---|---|
| `venues` | 载体目录 | 会议系列或期刊，使用独立且稳定的编号 |
| `calls` | 具体活动 | 某届会议、附属研讨会、期刊专题或持续栏目 |
| `venueId` | 所属载体编号 | 关联已有载体 |
| `kind` | 类型 | 主会、附属研讨会、专题、持续栏目分别保存 |
| `areas` | 研究方向 | 多选，必须使用方向表中的编号 |
| `topics` | 具体研究主题 | 多选稳定编号，期刊、会议、活动共用主题表 |
| `topicReviewedAt` | 分类整理日期 | 与官方事实核验日期分开记录 |
| `authorGuideUrl` / `cfpUrl` | 作者指南 / 征稿入口 | 可选；只补充已找到的官方入口 |
| `nodes` | 时间节点 | 投稿、摘要、录用、终稿等分别记录 |
| `verification` | 核验状态 | `verified` 已读取来源；`pending` 待核验 |
| `assessments` | 评价或目录依据 | 每项独立保存体系、年份、来源及适用说明 |
| `publicationType` | 刊物类别 | 研究型期刊、快报期刊、专题期刊、综述期刊、学术杂志 |
| `articleTypes` | 可投稿文章类型 | 研究论文、快报、综述、教程等，不能与刊物类别混同 |

期刊的投稿方式目前以“作者指南中核实”或明确的专题方式展示。没有逐刊确认时不统一写“全年接收”。

## 时间精度

`precision`（精度）可取：

- `instant`：明确时刻。`instant` 字符串必须包含 UTC（协调世界时）偏移，例如 `2026-10-30T23:59:59-12:00`；同时记录官网时区说明。此例仅说明格式，并非某个会议日期。
- `date`：仅日期。填写 `date`，`instant` 和 `timezone` 均保持空值。
- `unknown`：尚未确认，不生成倒计时或日期事件。

`original` 保存必要的官方日期短表述。不要把网页内容管理系统的文章发布时间当成投稿截止钟点。`requires` 是前置节点的稳定编号列表，例如全文投稿需要先完成摘要注册。

明确标注 AoE（全球任何地方当天结束）时采用 UTC−12。美国太平洋时间要按截止当天确定夏令时偏移，不用全年同一偏移。

官网有明确日期但未说明开放时间时，网站显示日期已公布，不据此保证投稿系统此刻已经开放。仅日期已过时显示“公布日期已过”，具体状态以官网为准。

## 延期、新轮次与取消

活动和节点编号不能随排序改变。延期更新日期，递增节点 `revision`（修订序号），保存旧值、变更依据和 `updatedAt`（更新时间）。新投稿轮次增加新的稳定节点编号。

取消时保留原节点，活动状态设为 `cancelled`（已取消），递增修订序号；生成的日历记录保留原 UID（事件唯一编号）并增加取消标记。停止维护的活动保留历史，避免订阅端失去修订依据。

本版 JSAC 可移动天线专题的官网注明已延期，但没有核实旧日期，因此只保留“已延期”的证据，不虚构此前数值。

## 已发现的来源问题

- 一些会议网站本次无法直接读取，因此其具体届次与日期保持待核验。
- 无线通信杂志水下无线光通信专题的官方页面存在首次决定年份早于初稿截止的异常。投稿截止与官方总表一致，已录入；异常通知节点没有自动纠正或写入。
- VTC 附属研讨会记录是大会官方总入口；具体研讨会可能有独立要求，需要逐一核实，不继承主会标签。
- JCR、SCIE/ESCI 按已读取的出版社快照；CCF公开副本与中科院第三方转录单独标注证据。当前学院政策不由历史文件自动推定。

## 提交流程

修改 `data/catalog.json` → 核对官方证据 → `npm test` → `npm run build` → 检查页面预览 → 提交变更。

格式校验只检查结构和业务约束。维护者仍须人工确认网址对应正确届次、摘要与全文区别、时间精度和学校文件范围。

有字段冲突时标记 `conflict`（冲突），保留来源说明；不要挑一个方便的日期直接发布。第三方日历只用于发现线索。

## 分类与筛选规则

方向代码 WC、SP、IT、NET、OPT、EM、SAT、IoT、AI 是本项目的导航缩写，不是 CCF 类别或等级。具体主题可属于多个方向；载体的方向与主题由编辑人工整理，不机械继承主题的所有上级方向。

多选具体主题匹配任一项，再与所选方向、关键词、类型等条件共同筛选。切换方向后清除不属于新方向的主题；筛选状态保存在地址中的 `topics` 参数，刷新与分享可恢复。未知主题编号会被忽略。主题旁数字表示当前方向、关键词、类型等条件下该主题的独立结果数，多主题合并后会去重。

具体专题使用自身主题和方向；母刊主题只是目录导航，不能自动扩展专题征稿范围。会议系列下独立运行的 SAM 等研讨会与附属于主会的 workshop（附属研讨会）不是同一层级。

SenSys、IPSN、IoTDI 合并后按统一 SenSys 系列计数，旧名称作为别名。MWTL 的旧称 MWCL 保留检索。目录来源可以是学会的出版物或会议总表；总表核验只支持载体身份与概括范围，不支持具体截止、录用率或最新学术等级。

## 评价数据结构与防误认规则

`evaluations`（评价记录）为每个体系独立保存 `system`（体系）、`year`（原表年份）、`releaseYear`（发布年，如有）、`snapshotDate`（快照日期，如有）、`value`（明确数值或空值）、`status`（证据状态）、`sourceUrl`（来源网址）、`sourceType`（来源类型）、`note`（范围说明）。中科院另存大类 `category` 及小类 `minorCategories`；大类筛选不悄悄取小类中的最高分区。

- `verified`：一手来源明确值；`reported`：第三方转录或原始文件公开副本，仍待原库复核。
- `pending`：待核验；`not-matched`：本次未能建立确定对应，不能作为“所有现行目录均未列入”的断言。
- `scope-review`：合并或改名后的适用范围待认定；`non-ranked`：原库明确的非等级状态，不映射为 C。
- 同缩写不能直接匹配：CL（IEEE通信快报）不是 Computer Languages（计算机语言）；IEEE CTW（通信理论研讨会）不是 Cologne-Twente（科隆—特温特图论研讨会）；中国通信 ICCC 不是计算创造力 ICCC。
- CCF会议评级仅适用于对应正式长文，附属研讨会、演示、短文等不自动继承；学校历史目录筛选同样排除附属研讨会继承。
- JCR和中科院分区仅适用于期刊。JCR Q1不能直接解释为SCIE收录，ESCI期刊也可能有JCR分区。
- 中国科学院文献情报中心[2026年3月声明](https://las.cas.cn/news/tzgg/202603/t20260327_8178738.html)明确自2026年起停止更新发布；新锐分区不能标成中科院2026版。

`catalogStatus`（目录状态）独立于评价：`current` 仅表示已有官方身份来源，不能保证每届仍在征稿；`needs-review` 为当前信息待核验；`historical-only` 为仅有历史文件记录。按名称与主题搜索仍可找到历史条目。

`legacyMappings`（原表映射）保存全部89个原编号、原简称、PDF页码和对应载体编号。`policy`（选用文件）保存版本、条款及适用范围，不因目录扩充而扩大毕业认定。

运行 `node scripts/coverage.cjs` 可从原始数据重新生成目录审计。不要把网页结构校验或测试通过当成外部事实已被证实。
