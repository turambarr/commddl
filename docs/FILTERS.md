# 搜索与筛选

更新：2026-10-19，v0.7.1。

## 常用操作

- 查SCI期刊：点“SCI期刊”，或在期刊目录点“SCI / SCIE”，按已录入版本匹配101本。
- 查SCI一区：点“SCI · 中科院一区”，匹配15本；继续选二区，匹配45本。
- 选研究主题：例如“多天线与波束成形”，与SCI、中科院一区组合匹配JSAC和TWC。
- 查中文核心：搜索“中文核心”，或点击“北大核心”；“科技核心”独立筛选。
- 查名称：输入TWC、中文名称、主题或旧简称。
- 查属性：输入`SCI 一区`、`SCI Q1`、`JCR Q2`、`中科院二区`、`CCF A`、`ICORE A*`，可接普通关键词，例如`SCI 一区 无线`。

SCI对应SCIE（科学引文索引扩展版），ESCI（新兴来源引文索引）单列；“一区”指中科院大类，Q1指JCR（期刊引证报告）分区。目录记录期刊索引，具体论文的入库状态按论文查询。

## 组合规则

同体系等级多选匹配任一项，例如中科院一区或二区。不同属性同时满足，例如SCI、中科院一区、JCR Q1。主题多选匹配任一项，再叠加方向及搜索条件。

搜索中的属性与按钮共同生效，已识别条件显示在输入框下。按钮与输入框各自保存条件；清空搜索或点击“清除全部”可解除。

数字表示保留其他条件时，各单项的匹配数量。索引可重叠，统计依据为已录入的明确证据。各期刊的来源、年份和信息缺口见详情。

## 目录与截稿

期刊目录查询全部载体，截稿页查询具体届次、专题和栏目。常规期刊与专题分别记录；附属研讨会、演示及独立分会按各自适用评级筛选。

筛选条件写入地址，可复制分享、刷新恢复。`index`（索引）、`ranks`（评级）、`topics`（主题）等地址参数保持兼容。
