# 名称容错与技术缩写更新

本次继续在 `fix/search-filter-ux` 分支完善本地搜索。范围为名称容错、可解释的近似结果、技术缩写与主题对应及实际浏览器回归；不修改期刊评级、会议截止、后台服务或部署配置。

## 搜索行为

- 准确匹配保留现有名称片段、旧简称和刊号检索。中文常见表达采用明确同义词，“通讯/通信”“波束赋形/波束成形”可对应。
- 默认排序对普通关键词优先匹配简称、正式名称、别名和名称片段，再排主题与简介；无普通关键词时沿用截止排序。手选名称或日期排序始终优先。
- 准确结果少于6项时，另列最多6项近似名称。英文5—8字母允许1次编辑，9字母以上最多2次；可处理相邻字母颠倒。每条查询累计最多2次编辑，超长或过多关键词不进行纠错。
- 3—4字母简称仅在独立候选区给建议，相邻字母颠倒的候选优先。已存在的简称、带数字的刊号、引号内文字不自动纠错。无中文任意错字推断。
- 近似结果经过与准确结果相同的学术属性、载体类型、方向、主题、日期、收藏和历史范围过滤。界面不重写输入；点击改词建议才更改相应文字，保留其他条件和原标点。
- 正常结果数量、分面计数与整组日历导出采用准确匹配，近似候选另行标识与计数。

## 技术缩写

`data/topics.yml` 新增可选 `terms` 字段，旧主题编号及 `aliases` 保留。24项词条关联16个现有主题，每项含缩写、中文解释、英文全称、常见写法、来源与核对日期。

技术缩写仅供内部检索映射使用，输入缩写、中英文名称后按对应主题匹配。主题按钮和卡片只显示原有主题名称，页面不增加缩写标签、悬浮释义或术语表；搜索条件按原有方式显示识别到的主题。

PNT（定位、导航与授时）与 SOP（机会信号）分别建词条，共同关联定位导航主题。术语关联不扩大任何载体、届次或专题的已维护范围。

来源采用 NASA（美国国家航空航天局）、FAA（美国联邦航空管理局）、ETSI（欧洲电信标准化协会）及3GPP（第三代合作伙伴计划）术语资料、IEEE（电气与电子工程师协会）出版方和 ION（美国导航学会）官方页面。PNT/GNSS 使用机构介绍；SOP/INS 使用 ION 官方会议论文摘要核对术语，未将摘要当作全文阅读。日期核对仅指本次术语记录。

## 验证入口

- `npm run check`：数据及新增术语字段校验。
- `npm test`：原功能及名称、术语、严格筛选边界测试。
- `npm run build`：静态站与离线单文件构建。
- `npm run test:browser`：独立浏览器中的搜索、纠错、内部缩写映射、日期/月历、手机和已有功能回归。

本地目录校验、180项自动测试、静态站和离线单文件构建、25组真实浏览器场景全部通过，无未处理的浏览器异常。浏览器场景覆盖改词保留条件、短简称建议、缩写及中英文名称与主题结果一致、主题不附加术语标注、分享参数、日期范围与月历、中文输入和手机布局。

浏览器回归使用独立临时用户目录，仅访问本地测试站点，包含390像素手机宽度下的搜索和主题展示。当前结果均为本地验证，不推送、不创建合并请求、不发布。
